    Software candidates

    This page tracks the software considered for each need of the home lab, keyed by need rather than by tool, so it answers "what do we use, or could use, for X". It complements the todo list in the specs index: only active evaluations become todo items there, and the rows below link to them.

    The Decision column uses these values:

    • settled: the tool in use is the choice; candidates stay as alternatives.
    • open: an active todo item exists, linked from the row.
    • backlog: no current need; options parked.
    • deferred: blocked on a prerequisite named in the row.
    • conditional: depends on a stated condition.
